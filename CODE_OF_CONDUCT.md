# 行为准则

## 报问题

贴报错原文，不要贴对话框截图。同一条报错在不同客户端里说法不一样，原文才认得出是哪一种。

顺带说清三件事：用的哪个客户端、卡在第几步、命令打印了什么。

## 什么会被关掉

- issue 里贴了 token、密钥或密码。贴出来就算泄露，先吊销，再开一个新的、不带值的。
- 要求加一步，但没说照着现有的那步做过之后哪里不对。

## 不同意

把你认为错的那句话引出来，写上你认为该写成什么。只说写得不好，我不知道改哪儿。

删评论或删一段文字，在楼里留一句为什么。

# Conduct

## Reporting a problem

Paste the error text instead of a screenshot of a dialog. The same failure is worded differently in each client, and only the wording identifies which one it is.

Also say which client you were in, which step you were on, and what the command printed.

## What gets closed

- An issue containing a token, a key or a password. Posting it is what leaks it, so revoke that credential and open a new issue without the value.
- A request to add a step, with nothing said about what went wrong when the existing step was tried.

## Disagreeing

Quote the sentence you think is wrong and write what it should say instead. Saying the writing is bad tells me nothing to change.

When you delete a comment or a paragraph, leave one line in the thread saying why.
