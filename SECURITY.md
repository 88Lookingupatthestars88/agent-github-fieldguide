# Security

## What this repository holds

Two Markdown files. No executable code, no dependencies, no build step. Nothing here runs on its own.

## The one thing worth reporting privately

The skills tell an agent how to handle GitHub credentials. A passage that would lead someone to paste a token into a file, a URL, a commit or an issue is a security bug in the text, and reporting it in public puts the technique in front of people who will use it.

Open a private report at https://github.com/88Lookingupatthestars88/agent-github-fieldguide/security/advisories/new, or email the address on the GitHub profile. Say which file and which line.

## Everything else

A wrong endpoint, a stale permission name, a step that fails on your client: those are ordinary bugs. Open an issue.
